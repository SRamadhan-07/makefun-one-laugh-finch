A tiny Python program for the make.fun "One Line, One Laugh" competition. It holds one funny line as data — an AI trained on all human knowledge that spends its days writing "per my last email" — and writes that line exactly to `/output/entry.txt` for judging.

## How to run

```bash
python3 main.py
```

This creates `/output` when needed and writes the entry to `/output/entry.txt`. The program uses only the Python standard library and prints nothing.
